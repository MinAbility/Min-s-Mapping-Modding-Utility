# Min's Modding & Mapping Tool
## A tool to help create, modify, and simplify map and modding Portal 2.

# Features
- Allows you to decompile and recompile BSP's
- List materials and entities in a given map
- A (wip) way to add other user scripts to the tool


# Setup
Download the latest binary from the [Actions](https://github.com/MinAbility/Min-s-Mapping-Modding-Utility/actions) page. Once that's downloaded you'll need the [BSPSRC Jar](https://github.com/ata4/bspsrc/releases) from the releases. Same goes for the [VPKEdit](https://github.com/craftablescience/VPKEdit/releases) CLI Binary path.

Once both of these are setup you'll be able to use the tool!
